Fourier Drawing.

Drawing with spinning arrows, and an idea for a Celeste level.

Why I tried it

I came across a YouTube video where rotating arrows somehow drew a picture. It looked almost like a trick. At the time, I was thinking about new level ideas for my Celeste mod, and I wondered whether Fourier series could give me something to build a level around.

Maths has always been something I enjoy picking up. In Grade 10, I took the AMC 10 and qualified for AIME. But this was a different reason to learn: I wanted to understand something I could actually watch, change, and maybe turn into part of a game. I started teaching myself the maths and trying it in Python.

So far, I’ve been working on the drawing. I’m still figuring out how I might use it in a Celeste level.

How it works

My code starts with twelve points around the letter I. I store them as complex numbers: one part gives the position across, the other the position up. A function called Lerp joins each point to the next with a straight line.

Fourier coefficients give each arrow its length and starting angle. Its frequency tells it how fast to spin and which way. The arrows join end to end, and the last tip leaves a trail as they spin. That trail makes the picture.

See the code and sources

This function joins two points in Lerp&FT.py:

def Lerp(A: complex, B: complex, t: float) -> complex:
    return (1 - t) * A + t * B

Here’s a shorter way to write the sum used in my animation:

point = sum(
    c * cmath.exp(1j * n * cmath.pi * t)
    for n, c in coefficients.items()
)

c is a coefficient, n is its frequency, and t is time. The slider changes how many non-zero arrows are added, in the Python order +1, −1, +3, −3, … .

Lerp&FT.py calls a separate maths file to find the coefficients. The browser drawing uses the saved letter_capital_i3 table in FT_Graphs2.py. The outline and arrows are both enlarged 30 times, as in the Python animation.

The corners are tricky

I noticed that straight sections were easier to match than corners, and some corners were much harder than others. Adding more arrows helps, but it doesn’t suddenly make every turn perfect. That’s the part I want to understand better.

Next, I want to test more shapes and different kinds of corners. I’m also still thinking about how these paths might fit into a Celeste level, rather than just being something interesting to look at.
